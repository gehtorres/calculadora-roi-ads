# 📊 Calculadora de ROI para Ads

Aplicação web desenvolvida para calcular o **Retorno sobre Investimento (ROI)** de campanhas de anúncios de forma simples e rápida.

## 🌐 Demonstração

[➡️ Acessar projeto online](https://gehtorres.github.io/calculadora-roi-ads/)

## ✨ Funcionalidades

* Cálculo automático do ROI
* Identificação de resultado positivo ou negativo
* Validação dos valores informados
* Interface simples e responsiva
* Exibição do retorno obtido sobre o investimento

## 🧮 Fórmula utilizada

`ROI = ((Retorno - Investimento) / Investimento) × 100`

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
